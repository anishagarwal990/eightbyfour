How this works
1. Green boxes are auto-detected shade swatches, with the code (and name, if the catalog prints one) read automatically via OCR. Click one — or drag on the page to draw your own box around a shade it missed — and a capture panel opens above the page, prefilled with what it read.

2. Auto-detection only finds flat-colour swatches — a wood grain, marble, or other textured finish has too much internal variation to pass that test, so it won't get a green box. OCR still reads the code fine either way, so a short blue dashed underline marks any code found with no matching box — drag your own box around the swatch just above it.

3. Check/fix the code and name, then click Main sheet or Edge band. Codes aren't assumed to follow any fixed prefix (SA, SD, M, etc. all work) — Main/Edge just need to share the same number to combine into one shade automatically.

4. Application photo is optional — only use it if the catalog has a lifestyle photo you want attached to a shade; pick which one from the dropdown.

5. Everything you've added shows up in "Collected shades" below — edit any field inline, remove a bad entry, then export once you're done.
